# WoW: Forever · Interactive Leveling Journey Atlas

An interactive World & Regional Map visualizing open-source 1–60 leveling routes across Azeroth for **World of Warcraft: Forever**.

## Open-Source Data Sources
- **Polestar Guide** (`fitzforge/polestar`) — Alliance & Horde 1–60 leveling routes
- **OpenXP** (`mjared123/OpenXP`) — Alliance & Horde 1–60 leveling routes
- **OpenMap** (`openmap-world/openmap`) — In-game hand-drawn parchment regional zone maps (including Riverglades, Shen'dralas, and Mount Hyjal)
- **WoW Forever Map** (`wowforevermap.com`) — Azeroth world map tiles & zone coordinate bounds

## Features
- Toggleable **Within-Region** questing loops, **Across-Region** travel arcs, and **Cross-Sea** continent voyages
- Interactive line hover tooltips, click-to-inspect leg cards, and animated journey playback with **Auto-Follow** camera
- Seamless **World Map ⇄ In-Game Parchment Regional Map** switching across all 49 zones (zoom in, double-click a zone, pick from the Region dropdown, or click any chapter; right-click or press `Esc` to return)
- Mobile-friendly pinch-to-zoom, 1-finger pan, slide-over chapters drawer, and Fullscreen mode (`F`)

## Deploy to GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch** → `main` / `/ (root)` → **Save**.
