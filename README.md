# ai-slop

A GitHub Pages monorepo for static web experiments and interactive tools.

**Hub:** https://andiwinata.github.io/ai-slop/

## Projects

- [**WoW: Forever · Interactive Leveling Journey Atlas**](./wow-forever-atlas/) ([Live](https://andiwinata.github.io/ai-slop/wow-forever-atlas/)) — An interactive World & Regional Map visualizing open-source 1–60 leveling routes across Azeroth for *World of Warcraft: Forever*.

## Adding a New Project

1. Create a new subfolder at the repo root (e.g., `my-project/`) containing an `index.html`.
2. Add a link to `./my-project/` in the root [`index.html`](./index.html) and this `README.md`.
3. Commit and push to `main` — GitHub Pages deploys directly from `main` (`/`) with `.nojekyll` enabled.
